Blender add-on for the Live for Speed vehicle editor

LFS SRE Tools

Open vehicle-editor .sre cars in Blender, edit them with real modelling tools, see them in the editor’s own light, and export them back.

In one minute

Quick start

  1. Install it with updates (Blender 4.2 or newer): Preferences›Get Extensions, the Repositories button at the top right, +, Add Remote Repository, paste https://byemk.github.io/lfs-sre-tools/index.json, Create, then search LFS and Install. Install has a picture of every click.
  2. File›Import›LFS SRE (.sre) and pick a car from your LFS data\3dob folder.
  3. Textures missing? Pick your LFS data\png folder in the box the LFS tab shows, and import again.
  4. Edit in Solid view. Material Preview shows the car in the LFS editor’s light.
  5. File›Export›LFS SRE into data\3dob and open it in the vehicle editor. A file you write over is kept as .sre.bak.
  6. Something wrong? Copy Bug Report at the bottom of the LFS SRE panel and paste it where you ask for help.

Start here

Install

You need Blender 4.2 or newer; it is tested on 4.2 LTS and 5.2. Install it from its update link and Blender keeps it up to date by itself. The orange numbers in the pictures are the clicks, in order.

  1. Click Edit 1, then Preferences 2.

  2. Click System 1 and tick Allow Online Access 2 under Network. Blender needs it to download extensions and to look for updates.

  3. Click Get Extensions 1, then the Repositories button at the top right 2.

  4. Click + 1 and choose Add Remote Repository 2.

  5. Paste https://byemk.github.io/lfs-sre-tools/index.json into URL 1, tick Check for Updates on Startup 2 and click Create 3.

  6. Type LFS in the search box 1 and click Install beside LFS SRE Tools 2. It is switched on straight away.

  7. Close the Preferences. With the mouse over the 3D View press N and click the LFS tab 1.

Without updates: drag lfs_sre_tools-2.0.1.zip onto the Blender window and press Install, or use Install from Disk… in the small arrow menu at the top right of Preferences›Add-ons. Keep the zip zipped. A copy installed this way never updates itself.

Search for LFS in the Add-ons list and click the arrow beside LFS SRE Tools to see its settings.

Its settings:

PNG Texture Folder
Your LFS texture folder (data\png). For imported cars you can leave it empty: the importer finds it next to the data\3dob folder the .sre is in. Set it if you start from FBX or OBJ models, because Bake Textures for LFS writes its pages there.
Build it on import
Builds the LFS look when a car is imported. A second Blender does that in the background for about half a minute, so switch it off on a slower PC: imports are quicker, and Build LFS look in the SRE Import panel makes the look when you want it.
Follow your edits
When you switch to Material Preview, the look first catches up with your edits. Off on a slower PC: the look stays as it is until you press Rebuild LFS look.
Show the LFS look
With the viewport shading (the default): Solid and Wireframe show the model you edit, the modes switched on below it show the LFS look. As a separate scene: the look gets its own scene and the LFS tab switches between the two.
Copy Bug Report
Copies the versions, these settings, the scene in short and the last messages, ready to paste where you ask for help. File paths are left out, so your user name stays private.

UpgradingIf you used the older single-file versions (LFS SRE Exporter, LFS SRE Importer), untick and remove them first. Two copies of the same tools register the same buttons and get in each other’s way; the LFS tab shows a red warning while both are on.

Set it up once

Getting updates

Installed from the update link (Install)? Then you are set: Blender looks for a new version when it starts and shows an Update button in Get Extensions. To look right away, click the small arrow at the far top right of Get Extensions and choose Refresh Remote. The update link is https://byemk.github.io/lfs-sre-tools/index.json.

  1. A copy you installed from the zip does not update. Remove it in Preferences›Add-ons first.
  2. Then add the update link as in Install and install LFS SRE Tools from Get Extensions.

From then on Blender tells you when there is a new version, and Update installs it. To look for updates Blender needs Allow Online Access (Preferences›System).

ShortcutThe release page, https://byemk.github.io/lfs-sre-tools/, has an lfs_sre_tools link: dragged onto Blender it adds the repository and installs in one go. That does not work from every browser; if nothing happens, use the steps above.

Check this on every PC

Folders on your PC

The add-on needs to know one folder: your LFS texture folder, data\png inside your LFS folder (for example C:\LFS\data\png). On your PC it may be found by itself; on someone else’s it may not, so check it once.

FolderWhere it isWhat to do
Texture folderdata\png in your LFS folderFound by itself when the .sre is in data\3dob, or when the car’s .png files sit next to the .sre. Anywhere else, set PNG Texture Folder in the add-on’s preferences or in the box in the SRE Import panel. Blender saves it with its preferences. Once a folder has been found, later imports in the same .blend use it too. With nothing found, it also looks in the usual LFS places (C:\LFS and the like on each drive).
Carsdata\3dob in your LFS folderImport from anywhere. Export into data\3dob so the vehicle editor lists the car.
Baked pagesthe texture folderBake Textures for LFS writes its pages there, so set the folder before baking a model from FBX or OBJ.

If textures are missing after an import, the status bar says how many texture pages were not found and which folder was searched. The SRE Import panel in the LFS tab then shows a box to pick the folder. Pick it and import again.

Not missingPages called s_mirr, s_clock or s_plate are drawn by LFS itself (mirror, clock, number plate). They are not files and are not counted.

Step 1

Import a car

Choose File›Import›LFS SRE (.sre) and pick a car from your LFS data\3dob folder. The SRE Import panel in the LFS tab has the same button.

Each sub-object of the file becomes one Blender object, named as in the editor. The textures load from data\png. The LFS look is built in the background; Blender stays usable while it builds, and the SRE Import panel shows LFS look: building… until it is ready.

Import optionDefaultWhat it does
LFS editor lookOnBuilds the display-only copy lit like the vehicle editor (next section).
Load TexturesOnLoads the texture pages the car uses from the texture folder.
LOD1 (Main)OnThe detailed faces you see up close. This is what you edit.
LOD2, LOD3OffThe low-detail faces LFS shows far away. They are kept in the file either way.
Recalculate NormalsOffLeave it off. Interiors and wheels face inward on purpose.
Split by Smooth GroupOnOnly for older .sre files that did not come from the vehicle editor.

Step 2

The look and the model

An imported car has two faces in Blender, and the viewport shading buttons (top right of the 3D View, or Z) switch between them.

  • The look follows your edits. Change the mesh in Solid, switch to Material Preview, and the look is rebuilt from what an export would write at that moment. You see the car the way the editor will show it before you export anything.
  • The mirrored side. Faces marked as mirrored in the .sre exist once in Blender. LFS draws their mirror image on the other side of the car, and so does the look. An import shows that side in Solid view too (import option Show mirrored side), also while you model: an edit on one side shows on the other at once. It is only for the eye: never exported and not selectable. Show Mirrored Side in the LFS SRE panel turns it off and on.
  • The lighting is in the LFS Look panel of the LFS tab: sun turn, height, strength and colour, shadow fill, sky reflections and the two paint colours. The defaults are measured from the LFS editor.
  • Blender compiles shaders before it shows the look for the first time, so give it a few seconds. Switching back and forth is quick after that.
  • On a slower PC switch off Build it on import and Follow your edits in the add-on’s preferences. Build or rebuild the look with the button in SRE Import when you want to see it.

Where the tools live

The LFS tab

Press N over the 3D View to open the sidebar, then pick the LFS tab on its right edge. Everything except import and export lives here.

LFS SRE
The sub-object count with a body check, Export to LFS, Find Bad Triangles, Rotate 180, Show Mirrored Side and Copy Bug Report. For a model from another format also Auto Setup and Bake Textures for LFS, and the closed Models from other formats section with its tools.
Material → cidx
Which LFS map each material exports to. cidx is the editor’s map number; imported materials already have theirs.
LFS Textures (per material)
Which texture page each material exports with.
SRE Sub-Objects
The car’s parts and their types, Select Added Faces, Join Selected Into…, Dish / Curve Part and the smoothing-group tools.
SRE Import
Import, switch between the look and the editable model, rebuild the look, and the texture folder in use.
LFS Look
The look’s lighting and where it shows.

Step 3

Edit and export

The imported objects are ordinary Blender meshes. Move points, extrude, cut, delete, add faces, swap materials. Work in Solid view and look at the result in Material Preview.

To export, use File›Export›LFS SRE (.sre) or Export to LFS in the LFS tab, then open the file in the LFS vehicle editor.

  • A sub-object you did not touch is written back byte for byte.
  • In a sub-object you edited, every face that is still where it was keeps its map, mirror flag, LOD and smoothing group from the file. New and changed faces take them from their material and their neighbours.
  • Export an unchanged import and you get the same file back. That makes a quick test that everything is in order.
  • The export window starts where the car went last, else where it came from, with its name. Writing over an .sre keeps the old file as name.sre.bak; to go back, rename it to .sre.
  • The status bar says when the car uses texture pages your data\png does not have (the editor shows them blank), and when the file is saved outside a data\3dob folder (the editor lists cars from there). A progress number on the cursor shows a big export is still working.

TipSave to a new file name and check it in the vehicle editor before you overwrite a car you care about.

How a car is built

Sub-objects and new parts

An .sre car is a list of sub-objects: one body plus parts such as wheels, the steering wheel, the mirror and the interior. In Blender each one is an object, and SRE Sub-Objects lists them with their type.

TypeShown asUsed for
0BodyThe main body. A car has exactly one; Export to LFS stays grey until it does.
3DetailMost parts: interior, trim, details. Auto Setup also uses it for wheels.
2SteeringThe steering wheel.
10MirrorThe interior rear-view mirror.
1GenericA generic part.
12WheelThe road wheels in cars made in the vehicle editor.
othertype NKept exactly as the file has it.
  • Click a type to change it. A small dialog opens with Keep as it is selected, so nothing changes by accident. The × beside it unmarks the part.
  • A part file (a single wheel or an interior .sre) has no body. That is fine: export it with File›Export.
  • Select Added Faces selects everything you modelled since the import in the active part. Handy on triangulated meshes.

Add a part to an imported car

  1. Model the part, or import or append it, in Solid view.
  2. Give it materials. One of the car’s own materials (paint, chrome, glass) makes it look like that part. A new material exports as its plain colour.
  3. Select it, open Join Selected Into… in SRE Sub-Objects and pick the part it belongs to, such as the body for a spoiler.
  4. Export. The new faces get smoothing groups by themselves (see below).

Why joinMark Selected Part(s) makes a separate new sub-object instead. On big cars it can stop with Map table too long, because the editor crashes past about 236 maps. A joined part uses the maps of the part it joins.

Shaping tool

Dish / Curve Part

Curves a part in or out with a smooth falloff: a dished wheel face, a domed panel, a concave diffuser, a flared lip. The centre, the axis and the radius come from the part itself, so nothing has to be dragged by hand.

  1. Select the part. In Object mode it works on the whole object; in Edit mode on the selected faces.
  2. Click Dish / Curve Part in SRE Sub-Objects.
  3. Open the panel at the bottom left of the 3D View (or press F9) and set Depth. Negative pulls the centre in, positive pushes it out. The first time, Depth is 0 and nothing moves until you set it; after that the button repeats your last settings.

WheelsFor a concave wheel, set Zone to Ring: the spokes bow in while the hub and the rim’s edge stay where they are. Centre moves the hub as well, and it comes out of the back of the rim (from the front it looks like a second rim behind the first).

SettingWhat it does
ShapeSmooth, Round, Cone, Bell, Power curve, or Custom curve (draw it yourself).
Depth (m)How far the centre moves. Negative = in (a dish), positive = out (a dome).
Start / End radiusWhere the curve starts and stops, as a share of the radius. 0.3 keeps the inner 30% flat, like a centre cap.
Taper (m)Also moves points sideways: negative narrows the middle, positive flares it.
ZoneStrongest at the centre, at the outer edge (a deep-dish lip) or halfway out (a ring).
AxisAuto uses the direction the part is thinnest in: the axle on a wheel.
CentreThe selection centre, the 3D cursor or the object origin.
From original shapeOn: re-applied from the shape before the first dish, so a smaller Depth makes it shallower again. Off: adds on top, to stack a dish and a lip.

Draw your own curve

Set Shape to Custom curve and the curve appears in the sidebar, under the Dish button.

  • Bottom is the centre of the part (Start radius), top is its edge (End radius).
  • The line starts straight up the middle: flat, nothing moves.
  • Bend it to the right and that ring moves by the Depth. The right edge is the whole Depth (it starts at 5 cm; change it in the settings panel). Left of the middle moves the other way.
  • Drag the points; Ctrl + click adds one. In Object mode the part follows while you drag, in Solid and in Material Preview; in Edit mode it follows when you let go.
  • Shapes loads a starting curve: flat, linear, smooth, round, bell, deep dish, lip or ring.

Shading

Smoothing groups

LFS shades by smoothing group, a number from 0 to 23 on every face (LFS has 24). Faces of one group that share a point blend smoothly; a different group makes a hard edge. Each face also has a contribution level (overridden, default, medium, high), and at each point only the faces with the highest level count.

What an export writes

  • A face that is still where it was in the file keeps its group.
  • A face you added or changed joins the group of a neighbour across a smooth edge: not marked sharp, under the smooth angle (Smooth angle in the export window, 30° by default), and shaded smooth.
  • Otherwise it gets a group that no face sharing a point with it uses. Extrusions come out crisp; a part welded on flush shades into the panel.
  • A group you set by hand always wins.
  • Every Blender face keeps one group, so a quad never gets a crease across its diagonal, and new groups stay within LFS’s 0 to 23.
New group
A group nothing else in the part uses: smooth inside the selection, a hard edge all round.
Join around
The group of the faces around the selection, so it shades into them.
Flat
A group of its own for every face: faceted.
Automatic
Forget what was set by hand and let the export decide.
Number…
Type a group number from 0 to 23, like in the editor.
Select group
Selects every face in the same group as the selected ones.
Shade like LFS
Sets Blender’s normals the way LFS will shade the part, worked out from the triangles the export writes, so you see the result before exporting. It marks the edges between different groups sharp, as the importer does, so Blender does not blend across them, and leaves flat and smooth faces as they are.

FBX, OBJ, glTF

Cars from other formats

For a model that did not come from an .sre:

  1. Import it into Blender. Blender units are metres; the export can also fit the car to its real length.
  2. Auto Setup groups the meshes by name into Body, Interior, Wheels and Steering, joins each group and marks them as sub-objects. Check that the LFS SRE panel says Body OK.
  3. Bake Textures for LFS turns the model’s UV textures into LFS texture pages and maps, and writes the pages into your LFS data\png folder. Until that folder is known, the LFS SRE panel shows a box to pick it. Reset Textures undoes the bake.
  4. Export to LFS and open the car in the vehicle editor.
  • The car faces backwards in LFS: Rotate 180 turns every part.
  • The tools for these models are in the closed Models from other formats section of the LFS SRE panel: Mark Selected Part(s) for a mesh Auto Setup missed, Prep Steering and Spin for a new steering wheel, the mesh repairs and the texture-map tools.
  • LFS draws each face from one side only. Fix Inside-Out Shells turns shells whose faces point inward; Mark Double-Sided makes thin sheets such as seat backs and glass visible from both sides. Mark Double-Sided doubles every sheet it finds, so check the triangle count afterwards.
  • Bake never writes over a page that is already in data\png. A model texture with the same name as one of the editor’s pages (a carpet.png, say) gets a name of its own, such as carpet_2, and each .blend keeps its own names for its baked pages.
  • Bake is for models from other formats. On a car imported from an .sre it says so and changes nothing: give a new part one of the car’s materials or a plain colour.

Troubleshooting

When something is off

Textures are missing

Keep the LFS folder layout, with data\3dob beside data\png, or set PNG Texture Folder in the add-on’s preferences. Then import again. SRE Import shows the texture folder in use.

Material Preview shows a plain model, not the look

The look may still be building (SRE Import says so), or it was switched off when you imported. Click Build LFS look in SRE Import. Also check Show the LFS look in the add-on’s preferences.

Undo took the LFS look away

The look has its own step, LFS look, in Edit›Undo History. Undoing past it goes back to before the look was built, and SRE Import says Undo removed the LFS look. Redo with Ctrl Shift Z, or click Build LFS look.

A dished wheel shows a second rim behind it

Dish with Zone Centre moved the hub and the inner spokes back, out of the rim. Undo, and dish again with Zone Ring: the spokes bow in, the hub and the rim’s edge stay.

The editor says “points have bad normals”

Usually triangles that stand exactly on the centre line of a mirrored part, often the wall an extrusion leaves along the centre. The mirror copy of such a triangle is the same triangle facing the other way, so their normals cancel. Delete them and export again. The export already warns about it, with the part and the number of points.

Every layer shows when I open the export in the modeller

The modeller does not save which layers are shown, whoever saved the file. The vehicle’s configurations keep that, in its .veh: load the model into the vehicle and each configuration shows its own layers again.

The export has two cars in it

An export writes every imported part in the scene, and importing a second car adds its parts beside the first (the importer warns about it). Delete the old car’s parts first, or import into a new scene.

Bake says the texture folder is not set

Pick your LFS data\png folder in the box in the LFS SRE panel, or set PNG Texture Folder in the add-on’s preferences, then bake again.

The car faces backwards in LFS

Click Rotate 180 and export again. (An older .blend may have Global Y-flip switched on: the LFS SRE panel then shows it in red; click it to switch it off.)

Export to LFS is grey

The scene needs exactly one body (type 0). The LFS SRE panel says No Body! or how many bodies it found. Part files without a body export from File›Export.

“Map table too long”

The vehicle editor crashes past about 236 maps. Run Purge Unused Maps, or run Bake Textures for LFS again (it stays under the limit). On an imported car, add parts with Join Selected Into….

Part of the car is invisible from one side in LFS

LFS draws faces from one side. Use Fix Inside-Out Shells for closed shapes, or Mark Double-Sided for thin sheets.

A new part shades with odd hard edges

Click Show under Smoothing groups to see what the export will write. In Edit mode, Join around blends faces into their neighbours; New group gives a clean hard edge all round. Shade like LFS previews the result.

The LFS tab shows a red warning

Another copy of the LFS SRE add-ons is switched on, usually the older single-file exporter or importer. Turn it off in Preferences›Add-ons; two copies register the same buttons.

Blender is slow or looks frozen

Watch the cursor: a number on it means an import, export or bake is still working. On a slower PC switch off Build it on import and Follow your edits for the LFS look in the add-on’s preferences.

Asking for help

Click Copy Bug Report (bottom of the LFS SRE panel, or the add-on’s preferences) and paste it with your question: it says which versions you have and what Blender reported.

The look takes a while to appear

Blender compiles shaders before it shows the look for the first time. Give it a few seconds; switching back and forth is quick after that. Right after an import the look may still be building.
