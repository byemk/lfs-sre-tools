LFS SRE Tools for Blender

Import, edit and export Live for Speed vehicle-editor .sre models. Blender 4.2 or newer.

Install with updates:
  1. Open Blender.
  2. Drag the lfs_sre_tools link below onto the Blender window. Blender adds this page as a repository and installs the add-on.
  3. From then on Blender tells you when there is a new version (it needs Allow Online Access in Preferences > System).
Or add the address of this page's index.json in Preferences > Get Extensions > Repositories > + > Add Remote Repository.
