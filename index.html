LFS SRE Tools for Blender

Import, edit and export Live for Speed vehicle-editor .sre models in Blender 4.2 or newer.

The install link

https://byemk.github.io/lfs-sre-tools/index.json

Add it to Blender once, as in the steps below (about two minutes). Blender then installs the add-on and keeps it up to date by itself.

Install, click by click

The orange numbers in each picture are the clicks, in order.

  1. Open the Preferences

    In Blender click Edit 1, then Preferences 2.

  2. Allow online access

    Click System 1 and tick Allow Online Access 2. Blender needs it to download the add-on and its updates.

  3. Open the repositories

    Click Get Extensions 1, then the Repositories button at the top right 2.

  4. Add a repository

    Click + 1 and choose Add Remote Repository 2.

  5. Paste the link

    Paste the link into URL 1 (Ctrl V), tick Check for Updates on Startup 2 and click Create 3.

    https://byemk.github.io/lfs-sre-tools/index.json

  6. Install

    Type LFS in the search box 1 and click Install 2. The add-on is switched on straight away.

  7. Find the tools

    Close the Preferences. Move the mouse over the 3D View, press N and click the LFS tab 1.

Updates

With Check for Updates on Startup ticked, Blender looks for a new version each time it starts: the status bar says Extension Update Available and Get Extensions shows an Update button. Not ticked? Get Extensions > Repositories (top right), click byemk.github.io and tick it, or tick it in the add-on’s preferences. To look right away: the small arrow (⌄) at the far top right of Get Extensions, Refresh Remote.

Had it before?

A copy installed from the zip file by hand does not update itself, and the old single-file LFS SRE Exporter / Importer clash with this one. Remove them in Preferences > Add-ons, then install as above.
